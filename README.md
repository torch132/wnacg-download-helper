# wnACG 更新助手

一个本地使用的 Chrome Manifest V3 扩展，用于手动检查 wnACG“韩漫 / 汉化”栏目的指定漫画更新，并将确认后的 ZIP 保存到用户授权目录。

## 安装

需要 Chrome 116 或更高版本。

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择克隆或解压后的 `wnacg-download-helper` 项目目录。

安装完成后，点击工具栏中的“wnACG 更新助手”图标，会打开 Chrome 原生 Side Panel，不会创建新标签页。侧栏打开后，点击网页空白处不会关闭，因此扫描和下载可以继续执行。Chrome 的侧栏左右位置是浏览器全局设置；如需固定在左侧，请在 Chrome 设置中将“侧边栏位置”设为左侧。

## 使用

1. 点击“选择目录”，选择你希望保存批量下载内容的目录并授予写入权限。
2. 在 wnACG 漫画列表或系列标签页点击扩展图标，输入完整漫画名前缀并添加关注。系列标签页会从第 1 页开始向后扫描，最多读取 15 页，所有匹配章节都会进入待处理队列，同时记录最新章节作为后续更新基线。
3. 点击“检查更新”。扩展会先补充当前系列标签页的历史章节，再扫描“韩漫 / 汉化”栏目；栏目扫描找到全部基线或达到 20 页后停止。
4. 勾选新章节，点击“下载选中项”。文件保存为 `漫画名/章节标题.zip`。

更新队列按漫画分组并默认收起，只显示漫画名和话数数量；点击组头即可展开或再次收起，当前侧栏会话中的展开状态会在界面刷新后保留。

关注列表中的系列基线只显示话数，例如完整标题“中了傳教士的美人計 34-35話”显示为“基线：34-35話”；完整标题仍保存在本地用于扫描判断。

漫画标题中的 `[中国翻訳]` 使用 `#ff677d` 高亮，`[DL版]` 使用 `#a8e6cf` 高亮，`[無修正]` 使用 `#6a9cbb` 高亮；高亮同时显示在 wnACG 页面卡片和扩展侧栏中，不会改变原始标题或下载文件名。

在 wnACG 主页、漫画列表、分类、标签或搜索页中，每张卡片的日期/图片数信息后会显示下载图标。点击后直接下载到 `漫画名/漫画标题.zip`；已关注漫画使用关注前缀作为目录名，其他漫画从章节标题推断目录名。Chrome 会为同名文件自动编号，不会覆盖原文件。扩展会按 aid 在本地查重，并在多个标签页同时点击时复用同一个下载任务。

Chrome 的下载 API 只能指定相对于“默认下载位置”的路径。请在 Chrome 设置中将默认下载位置设为系统的 `Downloads` 目录，并关闭“下载前询问每个文件的保存位置”，这样一键下载的实际路径就是 `Downloads/漫画名/漫画标题.zip`。侧栏中的批量下载仍写入你授权的外置目录，不受此设置影响。

一键下载只向 ZIP 地址发起一次文件请求，避免预检请求额外消耗站点限额。扩展会在 Chrome 确定文件名时再次强制 `漫画名/漫画标题.zip`，并在完成后校验真实保存路径、域名、MIME 和文件大小。若 Chrome 因文件名规则拒绝首选名称，会保留漫画目录并自动改用 `wnacg-aid.zip` 重试；若服务器暂时返回 503，按钮会变为失败状态，可稍后点击重试，扩展不会高频自动重试。

扩展不会定时检查，也不会在未确认时自动下载。目录权限失效或外置卷未挂载时，需要重新授权。点击网页不会关闭 Side Panel；若手动关闭侧栏或退出浏览器，未完成任务会在下次打开时显示为失败并可重试。

## 维护与发布约定

- 每次功能或修复更新都要同步递增 `manifest.json` 的版本号，并在发布前运行 `node --test`、JavaScript 语法检查、Manifest 文件引用检查和 `git diff --check`；测试未通过时不提交、不发布。
- 验证通过后，在 `main` 分支创建清晰的 Git commit，并 push 到 GitHub；不要只修改本地文件而遗漏远端同步。
- 代码注释、界面文案和错误提示优先使用简体中文；API、Chrome、Manifest、ZIP、MIME 等专业名词保留英文或标准缩写。
- 发布前检查 staged files，避免提交本机路径、凭据、下载产物和临时文件。
