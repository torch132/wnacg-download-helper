# wnACG 更新助手

一个本地使用的 Chrome Manifest V3 扩展，用于手动检查 wnACG“韩漫 / 汉化”栏目的指定漫画更新，并将确认后的 ZIP 保存到用户授权目录。

## 安装

需要 Chrome 116 或更高版本。

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择克隆或解压后的 `wnacg-download-helper` 项目目录。

安装完成后，点击工具栏中的“wnACG 更新助手”图标，会打开 Chrome 原生 Side Panel，不会创建新标签页。侧栏打开后，点击网页空白处不会关闭，因此扫描和下载可以继续执行。Chrome 的侧栏左右位置是浏览器全局设置；如需固定在左侧，请在 Chrome 设置中将“侧边栏位置”设为左侧。

界面会自动跟随浏览器或系统的亮暗模式：浅色使用 Catppuccin Latte，深色使用 Catppuccin Mocha，无需在扩展内手动切换。

## 使用

1. 使用侧栏关注与更新查重前，点击“选择漫画库”，选择包含 `漫画名/*.zip` 的本地根目录并授予只读权限。若旧漫画保存在 Chrome 默认 Downloads，就选择 Downloads；扩展不能未经授权自行遍历绝对路径。网页卡片上的一键下载按钮不需要这项授权。
2. 点击“选择目录”，选择你希望保存侧栏批量下载内容的目录并授予写入权限。漫画库与保存目录可以不同；检查更新时查重也会补充核对已授权的保存目录。
3. 在 wnACG 漫画列表或系列标签页点击扩展图标，输入完整漫画名前缀并添加关注。系列标签页会从第 1 页开始向后扫描，最多读取 15 页，匹配章节会先与本地 ZIP 核对；已存在的章节标记为已下载，仅缺失章节进入待下载队列。网站 aid 仍用于限定分页扫描范围，不作为本地已下载的证明。
4. 点击“检查更新”。扩展会先补充当前系列标签页的历史章节，再扫描“韩漫 / 汉化”栏目；栏目扫描找到全部网站边界或达到 20 页后停止。
5. 勾选新章节，点击“下载选中项”。文件保存为 `漫画名/章节标题.zip`；本按钮直接下载检查更新阶段已生成的选中队列，不再重复扫描本地漫画库。

本地查重只读取第一层 `漫画名/*.zip`：文件必须非空且有 ZIP 文件头，优先按标题或 aid 匹配，标题变化时仅在话数唯一且版本标签一致时认定为同一章。目录权限失效或选错根目录时会提示重新授权，不会把不可读取的目录当作空目录。旧独立话与合集子话仅在列表显示时折叠，原有进度记录不会被删除。

侧栏检测到带 `[無修正]`、`[无修正]` 或独立“無修正/无修正”字样的章节时，若同一漫画目录中只有一个话数范围完全相同、其他版本标签一致的普通版 ZIP，会将新版列为“将替换”。点击侧栏下载时，需要给旧 ZIP 所在的漫画库额外授予写入权限；新版 ZIP 写入完成且长度校验通过后才删除该普通版。下载或授权失败时旧文件保留。若新版已写好但旧文件删除失败，界面会保留明确警告，需手动处理旧文件。网页卡片的一键下载不参与本地洗版。

更新队列按漫画分组并默认收起，只显示漫画名和话数数量；点击组头即可展开或再次收起，当前侧栏会话中的展开状态会在界面刷新后保留。

关注列表中的系列基线只显示话数，例如完整标题“中了傳教士的美人計 34-35話”显示为“基线：34-35話”；完整标题仍保存在本地用于扫描判断。

漫画标题中的 `[中国翻訳]` 使用 `#ff677d` 高亮，`[DL版]` 使用 `#a8e6cf` 高亮，`[無修正]` 使用 `#6a9cbb` 高亮；高亮同时显示在 wnACG 页面卡片和扩展侧栏中，不会改变原始标题或下载文件名。

在 wnACG 主页、漫画列表、分类、标签或搜索页中，每张卡片的日期/图片数信息后会显示下载图标。点击后直接下载到 `漫画名/漫画标题.zip`；已关注漫画使用关注前缀作为目录名，其他漫画从章节标题推断目录名。网页按钮不读取漫画库、不要求目录授权，也不按本地文件或旧下载记录查重；一轮下载结束后再次点击会重新下载。Chrome 会为同名文件自动编号，不会覆盖原文件。同一 aid 在任务启动期间的并发点击会合并，防止误触创建重复任务。按钮显示的是最近一轮任务状态，不代表磁盘文件核验结果。

“合集”无论标注“连载中”还是“完结”，点击卡片下载按钮会一次建立全部子话的下载任务，并逐话保存为 `漫画名/子章节标题.zip`；状态字样不决定下载方式。下载页若只显示部分章节，会再读取章节接口补齐；卡片已标明“合集”但下载页缺少章节容器时，也会改从章节接口读取，不会误下父 aid 的单个 ZIP。清单数量不完整或接口无效时不会开始下载。合集超过 30 个子章节时会继续读取后续分页。再次点击合集按钮会重新下载当前全部子话，包括先前已成功的部分；每轮下载状态单独保存，旧记录不会被覆盖。

打开合集详情页后可以直接在侧栏输入对应漫画名前缀添加关注。侧栏会读取当前所有子章节 aid 作为网站扫描边界，显示“已记录 N 話”；此后手动检查会直接复查该合集的父 aid。是否需要下载由本地 ZIP 核对结果决定，因此合集不必出现在“韩漫／汉化”栏目里。即使列表卡片漏掉“合集”标签，已关注的同一合集仍会依据下载页章节清单复查。从系列标签页添加关注时，本地缺失的历史话数仍进入可选列表，供你按需补下。普通漫画保持单 ZIP 下载方式。

旧独立话并入合集后，扩展会按同一漫画的子 aid 在界面中折叠重复进度；原始记录保留在本地存储中，不会因折叠显示而删除。

Chrome 的下载 API 只能指定相对于“默认下载位置”的路径。请在 Chrome 设置中将默认下载位置设为系统的 `Downloads` 目录，并关闭“下载前询问每个文件的保存位置”，这样一键下载的实际路径就是 `Downloads/漫画名/漫画标题.zip`。侧栏中的批量下载仍写入你授权的外置目录，不受此设置影响。

一键下载只向 ZIP 地址发起一次文件请求，避免预检请求额外消耗站点限额。点击合集按钮时，第一话立即启动；只有 Chrome 确认前一话下载完成后，才再等待至少 1 秒启动下一话，同一合集不会同时提交多个 ZIP 下载任务。某话中断或创建失败时，余下话数暂停，不继续触发网络请求；再次点击会创建新批次并重新下载全话。普通漫画按钮和不同漫画的按钮不受合集队列限制。逐话串行可以减少突发请求，但不保证消除服务器限流或网络错误。扩展会在 Chrome 确定文件名时再次强制 `漫画名/漫画标题.zip`，并在完成后校验真实保存路径、域名、MIME 和文件大小。若 Chrome 因文件名规则拒绝首选名称，会保留漫画目录并自动改用 `wnacg-aid.zip` 重试；若服务器暂时返回 503，按钮会变为失败状态，可稍后点击重试，扩展不会高频自动重试。

扩展不会定时检查，也不会在未确认时自动下载。侧栏查重或批量下载所需的目录权限失效、外置卷未挂载时，需要重新授权；网页卡片下载按钮不受漫画库读取授权影响。点击网页不会关闭 Side Panel；若手动关闭侧栏或退出浏览器，未完成任务会在下次打开时显示为失败并可重试。

## 维护与发布约定

- 每次功能或修复更新都要同步递增 `manifest.json` 的版本号，并在发布前运行 `node --test`、JavaScript 语法检查、Manifest 文件引用检查和 `git diff --check`；测试未通过时不提交、不发布。
- 验证通过后，在 `main` 分支创建清晰的 Git commit，并 push 到 GitHub；不要只修改本地文件而遗漏远端同步。
- 代码注释、界面文案和错误提示优先使用简体中文；API、Chrome、Manifest、ZIP、MIME 等专业名词保留英文或标准缩写。
- 发布前检查 staged files，避免提交本机路径、凭据、下载产物和临时文件。
